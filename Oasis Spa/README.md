# 🍃Oasis Spa

## Descripción del Proyecto
El proposito Oasis Spa es diseñar y documentar una solución que permita optimizar la gestión de servicios, reservas y atención al cliente de nuetro spa, aplicando metodologías ágiles para la planificación, seguimiento y de las mismas.

## Problema que Resuelve
Actualmente, muchos procesos relacionados con la gestión de citas, servicios y atención al cliente se realizan de manera manual, lo que puede generar errores, retrasos y dificultades en el seguimiento de la información. Oasis Spa busca proponer una solución que facilite la organización y control de estos procesos.

## Producto a Desarrollar
Sistema de gestión para Oasis Spa que permita administrar:

- Clientes.
- Reservas y citas.
- Catálogo de servicios.
- Seguimiento de atención.
- Generación de reportes.
